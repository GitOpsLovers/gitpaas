# The advanced types of TypeScript

The type system beyond the ordinary use. This project uses `Pick`, `Omit`, `Partial` and `Record` everywhere, and those need no skill. Read this skill when the task asks for a generic utility type, a conditional type, a mapped type or a template literal type.

## The reference files

| The file | Read it when |
| --- | --- |
| [generics.md](references/generics.md) | You write a generic function, a constraint, or a default of a parameter of a type. |
| [conditional-types.md](references/conditional-types.md) | The type depends on another type, or you need `infer`. |
| [mapped-types.md](references/mapped-types.md) | You build a type from the keys of another type. |
| [template-literal-types.md](references/template-literal-types.md) | The type is a string that follows a pattern. |
| [utility-types.md](references/utility-types.md) | You write a utility type of your own, over the built-in ones. |
| [type-testing.md](references/type-testing.md) | You prove that a type resolves to what you expect. |
| [best-practices.md](references/best-practices.md) | You choose between two shapes, or you meet a known trap. |
| [performance.md](references/performance.md) | The compilation became slow. |
| [details.md](references/details.md) | You need an advanced pattern, or a technique of the inference. |

Read one reference file for your task. Do not read the whole folder.
